## 5. tuned's `mac_admin` denial: NOT ours, do not "fix"

`avc: denied { mac_admin } comm="chcon" scontext=tuned_t` ×2 at 17:58:09, same
second as `SELINUX_ERR op=setxattr invalid_context="system_u:object_r:
invalid_bootcinstall_testlabel_t:s0"` ×2 — that label string exists only in
`/usr/bin/bootc`. It is bootc's own *negative* test (assert an invalid label is
refused); the `chcon` is its child, in whatever domain the unit runs. Silencing
it means granting `tuned_t` `mac_admin` = arbitrary relabeling by a tuning
daemon. Leave the two lines of noise; mention upstream if ever reported.

## 9. Tooling traps on this dom0 (cost time today)

- **`sesearch`/`seinfo`/setools are NOT installed.** Empty `sesearch` output means
  "tool missing", not "rule absent" — I wrongly concluded a CIL module hadn't
  applied until I queried `libselinux.selinux_check_access` through ctypes.
  `audit2allow`, `checkmodule`, `semodule_package` DO exist (policycoreutils).
- `runcon -t xenstored_t ls …` fails on `entrypoint` (`rc=126`), so it cannot
  probe a foreign domain's file permissions at all — use `selinux_check_access`.
- `zcat /proc/config.gz` is unavailable; kernel config isn't in `/boot` either.
  Read the loader's flags from the *behaviour* (DMC `.xz` loads, so compression
  support is on) or from the kernel-core rpm.
- `systemctl status --no-pipe` doesn't exist (typo trap); `journalctl --since`
  takes local time (this box is EDT, image build timestamps are UTC — 21:31Z is
  the 17:31 boot).
- Do not `unbind` 00:02.0 on a live console to re-trigger the probe: fbcon is on
  `i915drmfb` and 10-03 §7 already showed the rebind path is fragile. A reboot is
  the honest test.
- **Pushing `../os` from this dom0:** the `origin` is HTTPS but there are no HTTPS
  credentials (`git push` → `could not read Username for 'https://github.com'`) and
  the local `gh` (`~/Downloads/gh_2.101.0_linux_amd64/bin/gh`, not on PATH) reports
  *"The token in default is invalid"* for jcpowermac. Port 22 to github.com is
  blocked; SSH-over-443 authenticates fine (key `id_ed25519` → "Hi jcpowermac!").
  So push with the one-off URL, no remote change needed:
  `git push ssh://git@ssh.github.com:443/jcpowermac/os.git main`
  and watch CI with the **unauthenticated** API (`curl -o file
  https://api.github.com/repos/jcpowermac/os/actions/runs?per_page=5`), since `gh
  run watch` needs the dead token.
